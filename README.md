# वाल्मीकि AI मास्टर (Valmiki AI Master)

यह प्रोजेक्ट Google Gemini 1.5 Flash API का उपयोग करके बनाया गया एक पूर्ण AI वेब एप्लीकेशन है जिसे GitHub और Render पर आसानी से डिप्लॉय किया जा सकता है।

## सुविधाएँ (Features):
1. **वॉइस-टू-टेक्स्ट (Voice Input):** माइक बटन दबाकर बोलकर सवाल पूछें। दोबारा दबाने पर रिकॉर्डिंग बंद होगी।
2. **टेक्स्ट-टू-स्पीच (Text to Speech):** AI का जवाब स्पीकर द्वारा बोलकर सुनाया जाएगा। साथ ही पॉज़ (Pause) और प्ले (Play) का विकल्प मौजूद है।
3. **कैमरा व फोटो अपलोड:** लाइव कैमरा से फोटो खींचकर या गैलरी से अपलोड करके AI से फोटो एडिटिंग या फोटो का विश्लेषण कराएं।
4. **फोटो डाउनलोड:** जनरेट या प्रोसेस फोटो को आसानी से डाउनलोड करें।
5. **ब्रांडिंग:** ऊपर "वाल्मीकि AI मास्टर" और साइड में "कंडेरा" लिखा हुआ है।

## Render पर Deploy करने के निर्देश:
1. अपनी **GEMINI_API_KEY** Google AI Studio से प्राप्त करें।
2. GitHub पर इस पूरे कोड को Push करें।
3. Render.com पर Web Service बनाएं और अपने GitHub Repository को कनेक्ट करें।
4. Environment Variables में:
   - `GEMINI_API_KEY`: आपकी जेमिनी एपीआई की (Key)
5. Build Command: `npm install`
6. Start Command: `node server.js`
